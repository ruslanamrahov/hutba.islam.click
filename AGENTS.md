# AGENTS.md

## Purpose

Static khutba catalog site [hutba.islam.click](https://hutba.islam.click). Content sourced from exported Telegram chat (`tg_chat/result.json`) and public Google Drive audio files. Astro 5 SSG + Tailwind v4 + shadcn/ui CSS tokens. Russian-only.

## Local Development

```bash
cd hutba.islam.click

```

## Data Pipeline

`npm run data` runs `parse_chat.py` → `parse_mockup.py` → `merge_data.py` in sequence. `scan_drive.py` and `scrape_abuyahya.py` are run independently when their sources change:

1. **`parse_chat.py`** — reads `tg_chat/result.json`, stream-parses catalog messages into khutba entries with number, title, year, and inline links (Telegram `t.me/hutby_abuyahya/NNN`, text `islam.click`, video `youtu.be`). Outputs intermediate JSON.
2. **`parse_mockup.py`** — parses `biblioteka_hutb_abuyahya.html` (reference design) for curated per-row links for 2014/2015/2016. Outputs `_mockup_links.json`.
3. **`scan_drive.py`** — Playwright script navigates year folders on `drive.google.com/drive/folders/1jsNA4_ISBlBRhFKQKey1ke9eV3Bh9nJE`, extracts file IDs and names. Run independently when Drive contents change.
4. **`scrape_abuyahya.py`** — fetches khutba number → category mapping from `abuyahya.net` WordPress API. Category source of truth. Run when abuyahya.net categories change.
5. **`merge_data.py`** — matches Telegram khutba titles to Drive audio filenames, applies abuyahya.net category mapping, enriches `textUrl`/`telegramUrl`/`videoUrl` from the mockup links (matched by `year`+`number`, non-destructive override), generates final `src/data/khutbas.json`.

## Design Conventions

The homepage replicates `biblioteka_hutb_abuyahya.html` (reference design) 1:1:
- **Homepage**: hero + search → native `<details>` year accordion (rows: number · title · ▶/🎙/📜/🎥/📄 links) → topic card grid (internal `/category/...` links) → "О проекте" box
- **Colors**: Green primary (`142.1 70.6% 45.3%`) + gold accent (`#e5b51b`), HSL token system via CSS custom properties
- **Font**: Inter Variable (body), no Arabic font needed (Russian-only)
- **Dark mode**: `.dark` class + `localStorage` + `prefers-color-scheme`
- **Cards**: `card-shadow`, `rounded-[14px]`, accent border on hover
- **Layout**: `max-w-[1280px]`, sticky header with `backdrop-blur`
- **Homepage classes**: `ay-*` prefix in `global.css` (year accordion, topic cards, about box)
- **No code comments**: unless explicitly asked

Note: the per-row ▶ button injects a native `<audio>` element (inline script in `index.astro`); the search filters rows client-side. The Vue `AudioPlayer` island is used only on `khutba/[id].astro`.

## Media Hosting

Audio and PDF files are hosted on **DigitalOcean Spaces** (bucket: `islamclick-coolify`, region: `ams3`). Public base URL: `https://islamclick-coolify.ams3.digitaloceanspaces.com`.

### Migration Pipeline (Google Drive → DO Spaces)

```
Google Drive (453 mp3)  ──→  scan_drive.py  ──→  _drive_files.json
      │                                                  │
      │                                      download_drive.py (Playwright)
      │                                                  │
      │                                      scripts/_downloads/ (453 files, 4.1 GB)
      │                                                  │
      │                                      upload_spaces.py (boto3)
      │                                                  │
      ▼                                                  ▼
tg_chat/files/ (22 pdf)  ──→  merge_data.py  ──→  khutbas.json (Spaces URLs)
```

### Audio URLs

Format: `{SPACES_BASE}/hutba/{folder}/{filename}`  
Example: `https://islamclick-coolify.ams3.digitaloceanspaces.com/hutba/2. Все хутбы 2015 года/Audio5. Наступил Рамадан.mp3`

Files use `Content-Type: audio/mpeg` + `Content-Disposition: inline` for native `<audio>` streaming (no CORS issues, unlike Google Drive).

### Re-scanning Google Drive

When Drive contents change:
```bash
python3 scripts/scan_drive.py       # Re-extract file IDs
python3 scripts/download_drive.py   # Download new files
python3 scripts/upload_spaces.py    # Upload to DO Spaces
npm run data && npm run build       # Regenerate + rebuild
```

Upload credentials are loaded from `../islamclick-infra.online/.env` (`DO_ENDPOINT`, `DO_ACCESS_KEY`, etc).

## Gotchas

- `khutbas.json` is regenerated via `npm run data` before each build
- Audio player is a Vue 3 island with `client:visible` for lazy loading (detail page only; homepage rows use a native `<audio>` injection)
- Year folders on Drive are numbered: `1. Все хутбы до 2015 года` through `10. Все хутбы 2023 года`
- Telegram catalog messages use mixed numbering: `🎙01 | Title` and `🎙⁰¹ | Title` — parser handles both
- `trailingSlash: 'never'` prevents path issues with static file output
- `build.format: 'file'` outputs flat `.html` files for clean URLs
- Russian "Коран"/"Куран" transliteration normalized during audio matching
- Thematic subfolders (Зуль-хиджжа, Сира, Сподвижники) are scanned recursively
- `year: 0` entries (thematic Drive subfolders without a year) render as the "Без года" accordion group
- `pdfUrl` defaults to the `https://t.me/alhadispdf` channel link for every entry (per-file PDFs override it when matched)
- In `getStaticPaths`, reference the raw `khutbasData` import directly — a locally derived `const` is not in scope there
